> [!NOTE]
> **Defensive Telemetry Dataset Authenticity Disclosure**:
> - **Windows Event Logs**: The lab runtime utilizes authentic, schema-compliant JSON-serialized Microsoft Windows Security Auditing records (MS-EVEN6 schema: Event IDs 4624, 4625, 4672, 4688, 4720, 4732, 4104, 1102) with custom CLI parsing utilities. Linux-based container runtimes do not execute proprietary Windows Server kernels or the Windows Event Viewer GUI.
> - **Linux Authentication Logs**: Pre-seeded `/var/log/auth.log` files provide realistic attack sequences (automated SSH dictionary brute force and sudo execution) without requiring days of aged operating system uptime.
> - **Network Traffic Captures (PCAPs)**: Captured `.pcap` files (`lab_traffic.pcap`, `suspicious_http_dns.pcap`) are programmatically synthesized libpcap binary structures dissected with authentic `tshark` and `tcpdump` protocol engines, not harvested from passive enterprise hardware SPAN taps.
